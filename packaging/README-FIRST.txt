================================================================================
  KATTVISION  -  please read this first
================================================================================

WHAT THIS IS
    A program that prepares court filing documents on your own computer.
    Nothing is uploaded anywhere. Your case documents never leave this PC.

HOW TO INSTALL IT (once, takes about a minute)
    1. Unzip the file you were given into a folder you will keep, for example
         C:\KattyVision
       IMPORTANT: unzip it. Do not run it from inside the zip.
    2. Open that folder and double click   Install.cmd
    3. If a blue window asks "Do you want to allow...", choose  Yes.
    4. Wait for it to finish. It prints DONE at the end.

    That is all. You do NOT need to install Python, and you do NOT need to be
    an administrator. Everything the program needs is already inside the folder.

ONE THING YOU MUST DO YOURSELF
    The bank seal is never included in the program, for security.
    Ask for the seal image, save it, and put it in this folder:

         C:\KattyVision\assets\stamp.png

    Until you do, the program opens and works, but it will refuse to put a
    stand-in seal on a filing. That is deliberate - we never want a fake seal
    on a real court document.

    (If Windows hides file extensions, make sure the file is called
     stamp.png and not stamp.png.txt)

HOW TO USE IT
    1. Put the case documents in the  "KattyVision - Documents"  folder on
       your Desktop (you can use sub-folders; order does not matter).
    2. Open  KattyVision  from the Desktop.
    3. Press  RUN.
    4. Finished files appear in the  output  folder, in a sub-folder named
       after your case, together with a report you can open.

WHEN YOU GET AN UPDATE
    You will be sent a new folder or a new zip. Unpack it straight over the
    top of your existing KattyVision folder and replace the files it asks
    about.

    It is safe to do this: your documents (input), your results (output), your
    settings and your seal are not part of an update, so they are left alone.

IF SOMETHING GOES WRONG
    Nothing you do can damage your case documents - the program always works
    on a copy and never overwrites your originals.
    If the program will not open, send a screenshot of the error to whoever
    gave it to you, along with the file  logs\startup_error.log  if it exists.

REMOVING IT
    Close the program, delete the KattyVision folder, and delete the two
    desktop icons. That is the whole uninstall. Nothing was installed on
    your computer.
